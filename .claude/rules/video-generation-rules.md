# Video / Content Generation Rules

이 프로젝트를 클론한 **모든 사용자에게 공통 적용**되는 콘텐츠 생성 원칙. custom 은 베타,
검증된 설정은 `marketing-studio-template` 로 이식되어 불특정 다수가 클론해 쓴다.

## ⛔ 1. 독립 생성 — 기존 결과 재사용 금지 (CRITICAL)

새 영상/콘텐츠는 **이번 요청의 references + brief 만으로 독립적으로** 만든다.
**특별한 지시가 없는 한, 이전 캠페인의 결과(콘텐츠·문구·씬 구성·출력물·크롭 자산)를 참고하거나 첨부하지 않는다.**

**Why**: 만들다 좋은 결과가 나오면 그걸 **깨끗하게 템플릿화**해 재사용 자산으로 승격한다.
매번 기존 결과를 끌어다 섞으면 오염되어 깨끗한 결과를 분리할 수 없다.

| 허용 (결과물 아님) | 금지 (기존 결과) |
|---|---|
| 파이프라인 코드(video-template, cardnews 모드 등) | 이전 캠페인의 씬 콘텐츠·문구·완성 영상 |
| `references/brand/` 등 명시적 공용 입력 | 이전 캠페인의 크롭 자산·프리셋을 임의 재사용 |
| **폴더/파일 구조 관례** | 다른 family 의 **컴포넌트·스키마·모티프·애니메이션 코드 복제** |

## ⛔ 2. 코드 재사용 한도 = 폴더 구조까지만 (CRITICAL)

새 family(카드뉴스 톤 등)를 만들 때 기존 family 에서 가져올 수 있는 건 **폴더/파일 구조 관례뿐**이다.
스키마·모티프·씬 컴포넌트·애니메이션 로직을 복사해 리페인트하지 않는다 — 그건 "기존 결과 재사용"이다.

- 각 family 는 **처음부터** 설계한다. 그래야 진짜 좋은 결과가 나왔을 때 그것이 특정 파생본이 아니라
  독립 자산이라 깨끗이 템플릿화된다.
- "기존 X 를 템플릿 삼아 빠르게" 는 **유저가 명시적으로 지시할 때만**.

## 3. 템플릿화는 명시적 · custom→template 승격

- 결과를 재사용 자산(family/preset/skill)으로 **승격하는 것은 유저의 명시적 결정**. 내가 알아서 하지 않는다.
- custom 에서 검증된 좋은 설정만 `marketing-studio-template` 에 동일 적용한다(민감정보 제외).

## ⛔ 4. agent 모드 역할 경계 — 전처리만, 상세 구성은 에이전트에 위임 (CRITICAL)

agent 모드에서 **Claude Code 가 하는 일은 "전처리"뿐**이다:
- **레퍼런스 분석** (포스터/브리프에서 제품지식·셀링포인트 추출)
- **프리셋 분석/생성** (voice/tone/color)
- **전체 영상 오버뷰** (무엇을·어떤 톤으로 — 압축 브리프 + 자산 매니페스트[파일명+추천용도])

**상세 영상 구성은 100% kvid.ai 에이전트에 위임한다** — 에이전트 system prompt 에 영상 생성 규칙이 이미 있다.
아래를 **message/프롬프트에 절대 넣지 않는다**:
- 씬별 길이·`durationSec`·"씬당 N초"
- 전체 길이 하드 제약 ("총 N초 이하", "정확히 30초" 등)
- 씬 순서·대본·자막 배치·타이밍 등 세부 구성

**Why (제일 중요)**: 에이전트는 **나레이션(음성) 길이에 맞춰 씬 길이를 자동으로 맞춘다.**
message 로 초/길이 제한을 걸면 이 자동 조정이 **깨져서** 음성이 잘리거나 씬이 비게 된다.
그래서 길이·타이밍 지시는 금지다. 목적은 "30~60초 광고 숏츠" 같은 **대략적 방향까지만**.

**✅ 이건 금지가 아니라 오히려 내 일(전처리 = 아트디렉터)** — 금지 대상은 "message 텍스트로 씬 길이/초/타이밍을 지시"하는 것뿐이다. 전처리는 **기계적 첨부가 아니라 분석·판단·생성**이다:
- ⛔ **레퍼런스 무지성 첨부 금지.** ref 는 분석 입력이지 씬 소재 의무가 아니다. **데이터를 분석해 무엇이 필요한지 판단**하고, **모든 씬이 ref 일 필요 없다**(생성 자산·인포그래픽·에이전트 b-roll 혼합).
- **필요 자산을 직접 생성**: 인포그래픽·모션 클립(Remotion), **신규 이미지(`kvid image generate`)·영상(`kvid video t2v`)**, 이미지 크롭·9:16 전처리, 카드뉴스 무음 마스터. 통제·정확성이 필요한 건 내가, 범용 b-roll·필러는 에이전트가.
- **배치·효과는 "강한 추천"** 으로 매니페스트에 담는다("이건 스펙 강조 씬에, 줌인으로"). 에이전트가 이를 따르되 **씬 길이는 음성에 맞춰 자동** — 즉 추천은 OK, 초 단위 하드 지시는 ❌.
→ 생성/선별한 에셋은 `attach` 로 넘기고, message 엔 자산별 "추천 배치/효과" 한 줄. (에셋·추천엔 길이 지시가 없음)

> direct 모드는 반대다 — 거기선 Claude 가 씬·타이밍을 직접 지정한다(그게 direct 를 쓰는 이유).
> **cardnews 모드**도 에이전트를 안 거치고 composition 을 직접 조립하므로, 씬 길이는 무음 마스터 분할로 Claude 가 정한다.
> 이 제약은 **agent 모드에만** 적용된다. 유저가 특정 길이를 꼭 강제하려면 direct/cardnews 모드로 가야 한다.

## 애매하면
"기존 X 를 참고할까요?" 를 먼저 물어보고 진행한다. 짐작으로 재사용하지 않는다.
