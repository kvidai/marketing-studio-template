# 시각 큐 — Short 05

## 전체 스타일
- 배경: 어두운 보라/남색, AI 첨단 기술 느낌
- 밝고 역동적 — 다른 쇼츠보다 희망적 톤

## [0-5s] 오프닝
- 중앙: "역사상 최고의 메모리 시황"
- 아래 붉은 텍스트: "2년"

## [5-35s] AI 공급망 시각화
- 다이어그램: AI Server → GPU (Nvidia H100) → HBM Memory (빛나는 한국 국기 색)
- 화살표: 수요 흐름
- 텍스트: "HBM = 한국의 현재 무기"

## [35-65s] 2년 카운트다운 인포그래픽
- 수평 타임라인: 2024-2025 (지금) / 2026 / 2027 (위험구간 빨간색)
- 타임라인 위: "AI 수요 급증 구간"
- 타임라인 아래 위협 표시: "엔비디아 자체 메모리 설계", "중국 HBM 추격"
- 텍스트: "이 창이 닫히기 전에"

## [65-90s] 클로징 인용
- 어두운 배경, 밝은 금색 텍스트
- "지금 이 순간을 지나면"
- "다음 기회가 언제 올지 아무도 모릅니다"
- — 권석준 교수, 차이나 반도체 라이징 저자
- 채널 로고 페이드인
