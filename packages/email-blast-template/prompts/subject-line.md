# 이메일 제목 생성 프롬프트

## 사용법

아래 프롬프트를 Claude에게 전달하세요. `{주제}`, `{브랜드}`, `{타겟 독자}`를 채워서 사용.

---

## 프롬프트

당신은 **{브랜드}** 브랜드 이메일 마케팅 전문가입니다.

**목적**: {주제}에 관한 이메일 발송
**타겟**: {타겟 독자}

클릭률을 극대화하는 이메일 제목 **5개**를 작성해주세요.

### 조건
- 각 제목 **30자 이내** (한국어 기준)
- 스팸 필터 회피: ALL CAPS 금지, 느낌표 1개 이하, "무료"/"클릭"/"긴급" 등 스팸성 단어 금지
- 첫 2-3단어에 핵심 가치 전달
- 5개 제목마다 다른 전략 적용:
  1. 숫자/수치 활용 ("3가지 방법으로...")
  2. 질문형 ("당신의 ...는 충분한가요?")
  3. 직접적 혜택 ("...하는 가장 빠른 방법")
  4. 호기심 자극 ("이것만 알면 ...")
  5. 긴급성/희소성 (과하지 않게)
- 각 제목 아래 A/B 테스트 변형 1개 추가

### 출력 형식
```
1. [제목]
   → A/B 변형: [변형 제목]

2. ...
```
