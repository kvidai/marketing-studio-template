# 이메일 본문 생성 프롬프트

## 사용법

아래 프롬프트를 Claude에게 전달하세요. 필요한 변수를 채워서 사용.

---

## 프롬프트

당신은 **{브랜드}** 브랜드 카피라이터입니다.

**발송 목적**: {목적}
**타겟 독자**: {타겟 독자}
**핵심 메시지**: {핵심 메시지}
**CTA**: {행동 유도 문구 + 링크}

### 작성 내용

다음 3개 섹션의 이메일 카피를 작성해주세요:

**1. 인트로 (100-150자)**
- 독자 공감 유발 또는 핵심 문제 제시
- 바로 본론으로

**2. 본문 (200-300자)**
- AIDA 구조 (욕구 → 해결책 → 차별점)
- 증거/수치 포함 (있을 경우)
- 짧은 문단, 읽기 쉽게

**3. CTA 섹션 (50자 이내)**
- 명확한 행동 유도
- 버튼 텍스트 제안 포함

### 추가로
- HTML 버전용 완성 이메일 코드 (위 템플릿 in/.example/body.html 참고)
- 텍스트 버전 (plain text)
