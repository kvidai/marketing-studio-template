# 마케터 사용법 (비개발자용)

이 스튜디오는 **Claude Code 에게 말로 시키면** 마케팅 콘텐츠(영상·이메일·카드뉴스·블로그·레딧)를 만들어 줍니다.
**JSON 편집·명령어·코드 몰라도 됩니다.** 하는 일은 딱 두 가지:
1. 참고자료를 **폴더에 넣기**
2. Claude Code 에게 **평소 말투로 요청하기**

---

## 1. 참고자료를 어디에 넣나요?

참고자료는 **"이름 붙인 세트"로 나눠서** 넣습니다. 여러 영상을 한 번에 만들 때 각 영상이 **필요한 세트만 지정**하므로 자료가 섞이지 않습니다.

### A. 상시 자료 → `references/`
- `references/brand/` — **전 콘텐츠 공통** 브랜드 자료(가이드·로고·톤·컬러). 항상 자동 적용.
- `references/<세트이름>/` — 제품·캠페인·주제 단위 묶음. 예: `references/신형아반떼/`, `references/여름세일2026/`.
  안에 아무 파일이나(제품정보 `.md`, 제품컷, 레퍼런스 영상, 스크립트 초안) 넣으면 됩니다.

### B. 이 영상 하나에만 쓸 1회성 자료
- `campaigns/<영상>/refs/` — 이 영상 전용 참고파일 (여기에 넣기)

> **마케터가 직접 만드는 파일은 없습니다.** `brief.md`(요청 기록)·`video.json`(구성) 등은 **Claude 가 만들고 채웁니다.**
> `brief.md` 는 "이런 요청이었다"를 남기는 **기록용** — 나중에 추적·재사용을 위해 Claude 가 자동 작성합니다.

### 어떤 세트를 쓸지 지정
요청할 때 **세트 이름만 말하면** 됩니다: 예) "신형아반떼 세트로 만들어줘".
→ Claude 가 그 영상 `brief.md` 에 `참고 세트: 신형아반떼` 로 기록하고, **brand(항상) + 지정한 세트만** 읽습니다.
(전체 references 를 뒤지지 않음 → 참조가 정확)

> 헷갈리면 그냥 파일을 채팅에 첨부하고 "이거 참고해서 만들어줘" 해도 됩니다.

---

## 2. 요청하는 법 (예시)

Claude Code 창에 그냥 이렇게 말하면 됩니다:

```
신형 아반떼 리뷰 영상 만들어줘.
- 제품 정보는 references/products 에 넣어놨어
- 15초 세로형, 톤은 우리 브랜드 가이드대로
- 핵심 3가지 통계는 인포그래픽으로 넣어줘
```

또는 자료를 먼저 폴더에 넣고:
```
campaigns/아반떼리뷰/refs 에 자료 넣어놨어. 그거 보고 홍보 영상 만들어줘.
```

그러면 Claude 가:
1. 참고자료(brief.md·refs·references·브랜드 톤)를 읽고
2. 필요한 **음성·이미지·영상·인포그래픽을 직접 생성**하고
3. **kvid.ai 프로젝트로 조립**해서
4. **에디터 링크**(`https://kvid.ai/en/editor/…`)를 줍니다.

---

## 2-1. 여러 영상을 한 번에

여러 영상이 **같은 자료를 공유**하면, 그 자료는 세트로 **한 번만** 넣고 각 영상이 그 세트를 가리킵니다(복사 안 함).

```
1. 공유 자료를 references/신형아반떼/ 에 한 번 넣음
2. 요청: "신형아반떼 세트로 영상 3개 만들어줘 —
         ① 15초 티저  ② 30초 기능소개  ③ 세로형 쇼츠"
3. Claude 가 영상별로 campaigns/아반떼-티저/, campaigns/아반떼-기능/, campaigns/아반떼-쇼츠/ 를 만들고
   각각 '참고 세트: 신형아반떼' 로 같은 자료를 참조 → 3개 각각 조립 → 링크 3개
```
- 영상마다 다른 자료가 있으면 그 영상 폴더의 `refs/` 에만 넣으면 됩니다.
- 세트를 안 나누고 references 에 다 몰아넣으면 어떤 영상이 뭘 쓸지 섞이니, **세트로 나누는 걸 권장**.

## 3. 결과 확인·수정

- Claude 가 준 **에디터 링크**를 브라우저에서 엽니다.
- kvid.ai 에디터에서 직접 **미세 수정**(자막 위치, 컷 길이 등) 후 **내보내기(export)** 합니다.
- 만든 원본 자료는 `campaigns/<이름>/assets/`, 기록은 `campaigns/<이름>/out/video/` 에 남습니다.

수정 요청도 말로 하면 됩니다: `자막을 더 크게, 2번째 씬을 3초로 줄여줘` → Claude 가 다시 조립해 줍니다.

---

## 4. 콘텐츠 종류별 시작

| 원하는 것 | 이렇게 말하거나 명령 |
|-----------|----------------------|
| 영상 | "○○ 영상 만들어줘" (또는 `/new-video`) |
| 여러 채널 한 번에 | "○○ 캠페인 만들어줘" (`/new-campaign`) |
| 이메일 / 카드뉴스 / 블로그 / 레딧 | "○○ 이메일 만들어줘" 등 (`/new-email-blast`, `/new-cardnews` …) |

## 자주 묻는 것

- **JSON·명령어 직접 써야 하나요?** 아니요. Claude 가 다 합니다. 말로만 하세요.
- **자료 형식은?** `.md`·이미지·영상·PDF 자유. 그냥 폴더에 넣으세요.
- **최종 영상은 어디서 받나요?** kvid.ai 에디터에서 export 합니다(정본). 로컬 사본은 원하면 Claude 가 `out/video/` 에 저장해 줍니다.
- **브랜드 톤이 안 맞아요.** `references/brand/` 를 채우면 다음부터 반영됩니다. 또는 "톤을 더 캐주얼하게" 처럼 말로 고치세요.
- **결과 품질이 예전 같아요 / 최신 기능이 안 돼요.** 가끔 **`pnpm doctor`** 한 번 실행하세요(또는 Claude 에게 "최신으로 업데이트해줘"). 레시피·CLI·스킬이 최신이 됩니다. **내 자료(`campaigns/`·`references/`)는 그대로 유지**됩니다. 영상 생성 시 도구가 오래됐으면 자동으로 "업데이트하세요" 안내가 뜹니다.
