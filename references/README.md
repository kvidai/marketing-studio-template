# references — 참고자료 (이름 세트 방식)

Claude Code 가 콘텐츠를 만들 때 참고하는 상시 자료. **타입별로 몰아넣지 않고, "이름 붙인 세트"로 나눕니다.**
여러 영상을 한 번에 만들 때 각 영상이 **필요한 세트만 지정**하므로 참조가 섞이지 않습니다.

## 구조

```
references/
├── brand/                  # 전역 공통 — 모든 콘텐츠에 항상 적용 (브랜드 가이드·로고·톤·컬러)
├── <세트이름>/             # 주제/제품/캠페인 단위 묶음 (필요한 영상만 지정해서 사용)
│   예) 신형아반떼/  여름세일2026/  브랜드리뉴얼/
└── ...
```

- **`brand/`** = 항상 자동 적용(전 콘텐츠 공통). 여기엔 진짜 공통 브랜드 자료만.
- **`<세트이름>/`** = 자유 이름 폴더. 안에 아무 파일(제품정보 `.md`, 제품컷, 레퍼런스 영상, 스크립트 초안)이나 넣기.
  - 세트 이름은 알아보기 쉽게: 제품명·캠페인명·주제.

## 영상이 세트를 지정하는 법

각 영상의 `campaigns/<영상>/brief.md` 첫 줄에 쓰거나, 요청할 때 말하면 됩니다:
```
참고 세트: 신형아반떼, 여름세일2026
```
→ Claude 는 **brand/(항상) + 지정한 세트만** 읽습니다. references 전체를 뒤지지 않음.

- 이 영상에만 쓸 1회성 자료는 세트 대신 `campaigns/<영상>/refs/` 에 넣어도 됩니다.
- **세트 목록 인덱스 파일은 없습니다** — 폴더 이름이 곧 목록. 세트는 자유롭게 만들고 지우면 됩니다.
- 사용법 전체: `docs/GUIDE.md`
